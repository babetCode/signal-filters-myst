---
title: Glossary
---

<u>**Continuous time**</u>  
A signal defined at every instant along a continuous time axis (often denoted \(x(t)\)), where t can take any real value.

<u>**Deterministic**</u>  
A signal or system whose future values can be exactly predicted from a known mathematical rule or past behavior, whith no randomness involved.

<u>**Discrete time**</u>  
A signal defined only at specific, separate instants (denoted x[n]), typically obtained by sampling a continuous signal at regular intervals.

<u>**Distributed**</u>  
A system whose parameters are distributed consistently over space, so behavior depends on both time and position. Described by partial differential equations (eg. a transmission line or a vibrating string).

<u>**Filter**</u>  
Any algorithm that selectively modifies or removes noise from a signal.

<u>**Linear**</u>  
A system that satisfies superposition: the response to a weighted sum of inputs equals the same weighted sum of the individual responses (additivity + homogeneity/scaling).

<u>**Lumped**</u>  
A system whose parameters are treated as concentrated at discrete points, ignoring spatial variation. Described by ordinary differential equations. Assumes signals act instantaneously throughout the system.

<u>**Measurement function**</u>  
A function that transforms the system model's state variables into the expected sensor observations.

<u>**Noise**</u>  
Any unwanted, unpredictable, or random component added to a signal that degrades or obscures the information it carries.

<u>**Non-linear**</u>  
A system that does not satisfy superposition; output is not simply proportional to input, and combined inputs don't produce a simply combined output.

<u>**Signal**</u>  
Any function that represents how a quantity varies over time or space.

<u>**Stochastic**</u>  
A signal or system that involves randomness or uncertainty; its future values can only be described in terms of probabilities, not exact predictions.

<u>**System**</u>  
Any physical entity or group of entities, delineated by some boundary.

<u>**System input**</u>  
Something outside a system which causes that system to change. Also known as control inputs.

<u>**System model**</u>  
A mathematical representation of a system that specifies how its internal state and inputs (if any) determine its outputs, and how it evolves over time. Also known as process model.

<u>**System output**</u>  
A signal produced by a system model according to some set of rules or operations.

<u>**System state**</u>  
The minimum set of variables such that, given only their values at the present time, together with the values of the input at the present and all future times, can be used to fully determine the system's defined outputs into the future (or their probability distribution if the system includes randomness).

<u>**Time invariant**</u>  
A system whose behavior/characteristics don't change over time: a time-shifted input produces an identically time-shifted output.

<u>**Time variant**</u>  
A system whose behavior changes over time, so the same input applied at different times can produce different (non-shifted-equivalent) outputs.
